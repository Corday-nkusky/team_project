# 技能开关可观测差异（TODO 1.4.1 / 第 5 课解题引导）

> 实测 2026-11-17 晚，五服务由 `up.mjs` 起，真实模型网关（`glm-5.3-flash`）开启。
> 原始输出：`reports/skill-toggle-run.log`。事实分级：【实测】本机请求与回答 /【代码】实现可确认。

---

## 1. 方法

同一道题、同一学生账号、同一份本班材料，只改一个变量：教师配置的技能 `enabled`。

1. 清理 apitest 遗留的测试技能（3 条），保证班级里只有受控技能，避免叠加干扰。
2. 新建技能 `toggle-6499a957`：`kind=solve_hint`、`enabled=false`，指令为
   「回答必须以【引导模式】开头。只给出一条思考提示，绝不给出定义或最终答案。」
3. 学生提问 → 记录 SSE `meta.skill` 与回答正文。
4. 同一技能 `enabled=true`（version 递增到 2）→ 再问同一题 → 记录。
5. 删除受控技能，恢复干净状态。

问题固定为：**「酶是什么？请依据本班材料回答。」**

## 2. 结果【实测】

| 项 | 技能关闭 | 技能开启 |
| --- | --- | --- |
| `meta.skill.name` | `""` | `toggle-6499a957` |
| `meta.skill.enabled` | `false` | `true` |
| `meta.skill.mode` | 无 | `solve_hint` |
| 回答开头 | 「酶是活细胞产生的生物催化剂，化学本质主要是蛋白质[4]。」 | 「【引导模式】思考提示：先在资料中寻找对酶的直接描述……」 |
| 是否给出定义 | **是**（直接给出定义 + 补充说明） | **否**（只给思考路径，要求自行概括） |
| 回答长度 | 150 字 | 106 字 |

两次回答**完全相同**：否。SSE `meta` 里的技能标记也由 `enabled=false` 变为带技能名和 `mode`。

## 3. 原始回答

**关闭：**

```text
酶是活细胞产生的生物催化剂，化学本质主要是蛋白质[4]。

补充说明：酶（enzyme）一词来自古希腊语，意为"在酵母中发酵"[3]；酶的命名通常是在催化底物或反应类型的名字后加"-ase"后缀，中文命名则类似地在名字后加"酶"，例如剪切乳糖的酶叫乳糖酶，催化DNA聚合反应的酶叫DNA聚合酶[3]。
```

**开启：**

```text
【引导模式】思考提示：先在资料中寻找对酶的直接描述——注意资料[4]中关于酶的来源、催化作用与化学本质的表述，再结合[3]中酶的历史与命名线索（如比希纳的研究和"-ase"命名法），试着用自己的话概括出酶是什么。
```

## 4. 判定

**开关确实产生了可观测的行为变化**：关闭时给定义，开启时只给引导、不给最终答案；`meta.skill` 同步标记当前技能与模式。教师可按班维护技能、启用/关闭，对应路由 `POST /api/skills`、`DELETE /api/skills/{id}`，前端入口为「技能与工具 → 解题引导技能」。

【代码】技能提示词叠加在 `qa.SystemPrompt()` 之上；无启用技能时逐字返回原提示词（单测 `TestNoSkillReturnsBasePromptVerbatim`）；技能加载失败只记日志、不阻断检索主路径（`TestReaderFailureDegradesToBase`）。

## 本篇没能验证的部分

- 模型回答受生成随机性影响，同一技能开启时措辞不完全可复现；判定依据是「是否给定义 / 是否带引导前缀」这类结构差异，不是逐字比对。
- 未测多条技能同时启用时的叠加顺序；本实验刻意只留一条技能以便隔离变量。
