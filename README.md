# CampusClaw 智教闭环

> 基于 RAG 与教学智能体的课堂疑问收集、个性化复习及教学反馈系统
> —— 北京大学「互联网软件开发技术与实践」课程小组项目

## 项目定位

面向**班级教学场景**，在现有教学知识库系统上做**增量开发**：

- **保留**已有能力：教师上传材料、班级权限隔离、文本切片、MySQL/Qdrant 混合检索、带引用的 RAG 问答。
- **继承** CampusClaw 第 5 课能力：智能体提示词、技能路由、多轮会话、SSE 流式回答。
- **新增目标**：把「学生即时提问 — 持续复习 — 教师反馈」打通成**可追踪的教学闭环**。

项目采用**真实业务数据与可解释的统计指标**，不把「问答次数」直接等同于「学习效果」。

## 核心功能模块

| 模块 | 做什么 |
|------|--------|
| **课堂疑问收集** | 学生在阅读材料或使用 AI 解题助手时，对知识点、材料片段或某次回答提交疑问；支持「仅教师可见 / 班级匿名展示」、疑问状态、相似问题合并、教师统一答疑；保留原文引用与会话来源。 |
| **个人学习路径** | 学生按知识点标记「已掌握 / 需要复习 / 仍有疑问」；关联材料片段、历史问答与疑问记录，自动生成待复习清单；按复习间隔与学习状态发出回顾提醒，允许手动调整掌握状态。 |
| **教学反馈看板** | 教师查看本班知识点疑问热度、未解决问题、材料引用频次与阶段变化；按知识点聚合共性问题，定位需补充讲解的内容；只看班级汇总，不向其他学生公开个人学习记录。 |

### 教学闭环流程

```
教师上传并组织班级材料
   → 学生使用智能体进行有引用的学习问答
   → 学生提交疑问并标记掌握状态
   → 系统将疑问和复习任务关联到知识点
   → 教师查看班级聚合反馈并集中答疑
   → 学生回顾复习、更新状态
```

## 技术方案

**系统架构**：React + TypeScript 前端 / Go REST 与 SSE API / MySQL 8.4 业务数据 / Qdrant 向量检索 / OpenAI 兼容模型网关 / Docker Compose + Nginx。复用现有 **JWT Bearer**、教师与学生 **RBAC** 及**班级隔离**机制。

| 模块 | 技术栈 | 实现方案 | 验收目标 |
|------|--------|----------|----------|
| 课堂疑问收集 | Go、MySQL、Qdrant、JWT | 建立疑问记录、状态及材料/知识点关联；以检索召回相似疑问，由教师确认合并；支持匿名班级展示与统一答疑。 | 学生可提交与追踪疑问；教师可处理共性问题；跨班数据不可见。 |
| 个人学习路径 | React、TypeScript、Go、MySQL | 按知识点保存掌握状态、关联材料与历史提问；依据状态和最近复习时间生成可解释的复习任务与提醒。 | 个人复习清单可持久化、更新和追溯；他人不可访问。 |
| 教学反馈看板 | React 图表、Go、MySQL | 按班级、知识点、状态及时间聚合疑问；展示高频知识点、未解决率、引用材料与变化趋势，支持过滤及查看来源。 | 教师可查看本班指标和原始记录，学生个人明细不被泄露。 |
| 智能体与 RAG 集成 | Go、Qdrant、SSE、LLM API | 复用 JWT 权限、混合检索、智能体技能路由、多轮会话及流式回答；在引用位置添加「提交疑问」及「加入复习」入口。 | 新模块能关联真实材料和引用；既有检索、问答及 SSE 无回归。 |
| 测试与部署 | OpenAPI、Python、Docker Compose、Nginx | 维护 Swagger 文档、Go/React 单测及接口自动化；增加权限负向用例、数据持久化校验和集成部署测试。 | 一键部署可用；验收用例可复现并输出测试报告。 |
