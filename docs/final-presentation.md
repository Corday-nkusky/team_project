# CampusClaw 5 分钟汇报稿

> 按报告六节顺序，课堂不现场跑环境；数字以 `reports/` 中最终原始输出为准。

## 0:00–0:30｜一句话产品定位

CampusClaw 是一个面向班级教学的知识工作台：教师上传材料，学生只在本班资料中提问，得到带原文引用的流式回答；没有依据时固定回答“资料中未找到相关内容”。系统从零实现认证、班级隔离、异步索引、技能与 MCP，不是给既有演示系统加界面。

## 0:30–1:20｜AI 写了什么，人负责什么

我们用 Qoder 按 OpenSpec 四件套完成 AI 原生开发。AI 产出主要包括四类：Go 后端与 MySQL 迁移，React 页面，检索、技能和 MCP 链路，以及测试、门禁和验收脚本。关键入口是 `backend/internal/`、`frontend/src/`、`scripts/` 和 `openspec/`。

人负责判断产出能不能合入：先对照规约逐段审核，再跑机器门禁，最后复核并发、事务和权限。没有通过测试或缺少外部条件的项目，不写成“已完成”。

## 1:20–2:15｜审核记录

审核不是只看“能跑”。`AGENTS.md` 把核查对象固定为接口入口、业务逻辑、数据库、公共函数、错误处理、安全隐私和性能七类，每类都有脚本、测试或走查手段。`reports/review-01.md` 到 `review-03.md` 保留检查方法、判据和结论。

本轮安全复测还发现并修复了两类问题：Go 与 Vite 的可达或高危依赖，以及正常拒答被错误计入技能失败率。15 题评测初期暴露了“课堂标记”等通用措辞造成无关片段误判；我们保留红色结果，补回归测试、修证据判定后在干净卷复跑为 15/15，而不是删掉失败题。

## 2:15–3:10｜高风险三查

并发方面，同一班同一内容重复上传由数据库唯一约束复用任务，切片和向量点不翻倍，证据在 `reports/risk-concurrency.md`。

事务方面，材料与任务在同一事务写入；停 worker 时任务保持 pending，恢复后继续执行，不产生半条材料或孤儿任务，证据在 `reports/risk-transaction.md`。

权限方面，所有业务检索带班级约束，跨班读取统一 404，学生写教师接口返回 403；新增观测接口的学生拒绝也写入只增审计，证据在 `reports/risk-authz.md` 和 `reports/observability-api.json`。

## 3:10–4:20｜门禁、性能与演示证据

本地 `node scripts/quality-gate.mjs --with-spec` 覆盖配置、分层、密钥、格式、构建、vet、单测和 OpenSpec；`node scripts/security-gate.mjs` 追加 SQL/XSS/CSRF 常驻反例、govulncheck 与 npm audit。最终 Go 可达漏洞和 npm 高危漏洞均为 0。CI 配置有 check、check-security、image-version 三个 job；本机已验证镜像版本可由 `/health` 反查，但不把本机结果冒充远端 Actions 已运行。

性能改进采用按班隔离、写后失效的两秒材料列表缓存。同脚本同参数下，C=1、4、8 吞吐分别提升约 74.4%、50.3%、19.9%，错误均为 0；C=8 的 P95 仍为 4ms，不宣称所有指标都改善。

最终回归使用新目录和全新数据卷，一条命令启动五服务，健康检查 MySQL/Qdrant 全通。接口、H5、浏览器、异步和技能/MCP 的原始结果都在 `reports/`；15 题覆盖有答案、无答案和跨班各 5 道，并检查引用与提示词版本。

## 4:20–5:00｜复盘与边界

代价最大的返工是 RAG 链路重写：固定窗口切片、全表打分和硬加权，改为结构切片、BM25、向量、RRF 与精排。教训是先判断做法是否成立，再调参数；本轮通用措辞误判再次说明，评测失败必须追溯检索与证据逻辑，不能靠调题碰绿。

仍未由本轮工作区完成的事项明确保留：真实公网地址、三名真实用户反馈、同伴签字、真实手机浏览器，以及网盘录屏链接。它们需要外部人员或账号，不伪造证据。
