# Design

## Context

材料表已保存不可变原文（`materials.content`），`store.GetMaterial(id, classID)` 也已按班级过滤；缺少的是对外读取接口与前端阅读界面。回答中的引用只携带切片（≤ 300 字），不能替代整篇材料。

本 change 在既有分层内补齐「材料列表 → 原文」的最后一段，不触碰上传、索引、检索与问答链路。

## API 契约

`GET /api/materials/{id}`，需要登录，教师与学生均可读取本班材料。

成功（200）：

```json
{
  "id": 12,
  "title": "第一节讲义",
  "content": "……完整原文……",
  "index_status": "ready",
  "index_error": "",
  "owner_id": 2,
  "created_at": "2026-11-01T02:03:04Z"
}
```

失败：

| 情形 | 状态码 | code | 说明 |
| --- | --- | --- | --- |
| 未携带/无效 access token | 401 | `unauthorized` | 沿用现有鉴权中间件 |
| `{id}` 不是正整数 | 400 | `bad_request` | 不查询数据库 |
| 本班不存在该 id，或该 id 属于他班 | 404 | `not_found` | 两种情形响应完全一致，不泄漏存在性 |
| 数据库查询失败 | 500 | `internal` | 只记结构化错误日志，不回显 SQL/内容 |

`content` 始终返回落库原文，不因 `pending` / `failed` 而拒绝；索引状态只作为元数据展示。列表接口不增加 `content`，避免大正文拖慢列表与扩大泄漏面。

## UI 结构

- 材料列表的标题单元格内使用原生 `<button>`，整段标题可聚焦、可 Enter/Space 打开；尾部箭头图标提示可进入。
- 阅读面板为右侧抽屉（宽屏 `min(720px, 100vw)`，窄屏 100%），背景遮罩；`role="dialog"` + `aria-modal="true"`，标题通过 `aria-labelledby` 关联。
- 面板头部：材料标题、索引状态徽标、上传时间、关闭按钮；正文使用 `<pre>` + `white-space: pre-wrap`，保留换行与空格，不解析 Markdown/HTML。
- 状态：
  - 加载中：显示进度提示，不提前渲染空正文；
  - 错误：显示可读错误与「重试读取」，重试同一 id；
  - 空正文：显示「材料正文为空」；
  - 正常：完整正文与元数据。
- 键盘：打开后焦点落到关闭按钮；Tab 在面板内循环；Esc 关闭；关闭后焦点回到发起阅读的标题按钮。
- 打开面板时锁定 `body` 滚动，关闭时恢复；打开另一篇材料复用同一面板并重新请求。

## 实现选择

### D1 新增单篇读取接口，而不是在列表里带正文

列表按班级返回全部材料，正文最大 32 MiB；把正文放进列表会让每次进入材料页都传输全部内容，且扩大响应泄漏面。按 id 读取只取用户真正打开的那一篇，也便于单独做 404/401 断言。

### D2 复用 `store.GetMaterial`，不新增查询

`GetMaterial` 已按 `id AND class_id` 查询并返回 `ErrNotFound`，与跨班 404 语义一致。handler 只做参数解析、错误映射和视图组装，符合「httpapi 不写业务」。

### D3 用原生 dialog 语义与焦点管理，不引入组件库

抽屉用原生元素与 CSS 完成。焦点陷阱只处理可聚焦控件循环，逻辑小且可测；不引入运行时 UI 依赖，保持前端零新增包。

### D4 正文按纯文本渲染

材料可能包含 `<script>`、Markdown 标记或任意用户文本。React 文本节点会转义，`<pre>` 保留排版；不提供 `dangerouslySetInnerHTML`，不引入 Markdown 渲染器，安全边界最小。

## 失败路径

- 跨班/不存在：404，响应体不含标题、正文或材料是否存在的信息。
- 非法 id：400，不发生数据库查询。
- 未认证：401，沿用统一错误体。
- 数据库失败：500，仅日志记录底层错误。
- 前端请求失败：面板显示错误与重试，列表本身不被清空。
- 空正文：显示空态而不是空白面板。

## 验证策略

- Go e2e：教师上传后读取本班材料，标题、正文、状态一致；学生读取同一材料成功；A 班用户读取 B 班 id 返回 404 且不含 B 的独有词；未认证 401；非法 id 400；把材料置为 `failed` 后仍能读到原文。
- httpapi 单测：非法 id 在触达存储前返回 400。
- 浏览器 e2e：教师点击刚上传材料标题，读到全文与尾注；Esc 关闭且焦点回到标题；学生可读且仍无上传控件；用 fetch mock 覆盖加载中、错误重试与空正文；524px 无页面级横向溢出。
- 全量回归：`node scripts/quality-gate.mjs --with-spec --with-e2e` 与 `node scripts/e2e-ui.mjs` 退出码均为 0。
