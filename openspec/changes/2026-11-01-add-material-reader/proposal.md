# Proposal

## Why

当前材料页只能看到标题、索引状态和上传时间，无法点开阅读原文；学生核对答案时只能依赖回答里的 300 字切片，教师上传后也无法确认系统实际保存了什么。材料列表因此停在“知道有哪些材料”，没有完成“能读到材料”。

价值三问：

- **谁的问题**：需要核对原文的学生、上传后想确认内容是否完整的教师，以及在评审/演示中需要证明“回答可追溯”的成员。
- **不做会怎样**：界面承诺与可操作能力之间有缺口；学生只能相信切片摘要，无法回到整篇材料；教师无法自查落库内容，发现正文异常也只能靠数据库。
- **做完如何验证**：本班教师与学生都能从列表打开一篇材料并读到完整正文；跨班读取返回 404 且不含对方内容；未登录返回 401；加载失败有可重试错误；加载、错误、空正文、正常四态可见；键盘可打开/关闭且焦点回到触发控件；320–1440px 无页面级横向溢出。

## What Changes

1. 新增登录后可用的 `GET /api/materials/{id}`：按 `class_id` 读取本班材料的标题、正文、索引状态与上传时间；跨班与不存在统一 404，非法 id 400，未认证 401。
2. 材料列表的标题改为可键盘聚焦的阅读入口；点击后以侧边阅读面板展示纯文本正文、索引状态和上传时间。
3. 阅读面板覆盖加载中、错误（可重试）、空正文与正常四态；Esc 关闭并把焦点还给触发按钮，窄屏占满可用宽度。
4. 补 Go 接口 e2e、httpapi 单测与浏览器 e2e；更新项目状态说明。

## Capabilities

### New Capabilities

- `material-reading`：本班材料原文读取接口与材料页阅读面板的统一契约。

### Modified Capabilities

（无；既有上传、列表、检索、问答与错误契约不变。）

## Non-goals（本次不做）

| 项 | 原因 |
| --- | --- |
| 材料编辑、删除、下载、版本历史 | 属于新的写能力与数据语义，需单独的权限、审计与迁移设计 |
| 在材料内搜索、目录跳转、分页 | 当前正文读取先做完整展示，检索仍由问答链路承担 |
| Markdown/HTML 渲染 | 会增加 XSS 与依赖审计面，本 change 明确按纯文本展示 |
| 从引用面板直接跳到材料全文并高亮命中片段 | 跨页面定位与切片高亮需要新的交互契约，另开 change |
| 读取行为写审计 | 现有规约只要求登录、上传、问答留痕；阅读审计需先明确隐私与数据保留边界 |
| 修改材料列表接口返回正文 | 列表会因大正文变慢并扩大泄漏面；正文只走按 id 的单篇接口 |

## Impact

- **后端**：`backend/internal/httpapi/router.go`、`materials.go`、`materials_test.go`；复用现有 `store.GetMaterial`（已带 `class_id`）。
- **前端**：`frontend/src/api.ts`、`pages/MaterialsPage.tsx`、`styles.css`、`components/Icon.tsx`。
- **验收**：`backend/cmd/e2e/main.go` 增加本班读取、跨班 404、未认证与非法 id、索引失败仍可读；`scripts/e2e-ui.mjs` 增加教师/学生阅读、加载/错误/空态、Esc 与焦点回归、窄屏检查。
- **文档**：`docs/project-status-guide.html` 的状态、接口清单与 e2e 计数。
- **兼容**：不改变材料列表响应、上传、重索引、检索与问答；既有浏览器 e2e 的 selector 与断言保持不变。
