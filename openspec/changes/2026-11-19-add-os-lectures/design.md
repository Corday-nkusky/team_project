# 设计

六份最终正文以 Markdown 保存，corpus.json 描述标题和文件映射。操作系统入口先读取并检查 UTF-8 文本，再转换为现有 biology 导入器接受的临时 corpus 格式，通过显式路径复用登录、去重、异步上传和轮询。临时转换文件在退出时清理，运行清单不纳入 Git。

通用导入器保留默认生物学行为；可选 CORPUS_PATH、MANIFEST_PATH、EXPECTED_CLASS_ID 仅用于本次复用。操作系统入口固定班级 1 并要求教师身份。凭据来自 SEED_USER/SEED_PASS；演示默认值沿用项目已公开的种子账号。令牌只保存在内存中，不输出或写入清单。

相同标题且正文相同的 ready 材料跳过；同标题正文不同则失败，不静默覆盖不可变原文。导入失败保留已成功记录，再次运行按标题跳过；数据库唯一内容约束承担并发去重。来源及许可独立保存，不注入讲义正文。

合并前需另一位组员按既有 peer-review 清单评审；本提交不代签，不自动合入 main。评审和门禁完成后再归档 OpenSpec。
