# Proposal

## Why

现网检索不是参数没调好，是整条链路的做法不成立：固定 500 字窗口切片丢弃标题层级与语境；每次提问把本班全部 `ready` 切片读进 Go 内存、逐片分词、统计全语料 DF、算 BM25 近似分并全量排序；向量路只取 `topK*3` 条，再把量纲不可比的两路分数按 `0.6/0.4` 硬乘；「有依据」被写死成提问里命中不少于 2 个内容词；召回完直接塞进提示词，没有查询理解、没有重排、没有上下文组织。这是关键词检索挂了一个向量，不是 RAG。改 `limit`、调阈值、把 2 降到 1 都不动主干。

本次把**切片、召回、精排、判定、语境组装整条重写**，全部本地自研，按中文教学材料、班级隔离与零密钥降级客制化。检索侧唯一外部调用是一次批量 embedding；重排是本地算法，不接 rerank 服务，也不为检索发起任何生成式调用。

## 目标架构

1. **结构切片**：`SplitDocument` 按 Markdown 标题、中文编号小节、段落与句子边界切 200–300 字子块，记录 `heading_path`（材料标题 > 章节路径）；嵌入文本带该路径前缀，回答引用仍是子块纯原文。
2. **查询变体**：本地规则为短概念问句追加一个去疑问词的概念短语，与原句合成**一次批量 `Embed`**；不生成假设性答案，不引入材料外事实，长问题保持单路。
3. **多路召回**：自研 BM25 倒排索引（只访问命中词元的 posting list）+ dense 多路（原句与概念短语向量并行查 Qdrant，均带 `class_id` 过滤）+ 结构路径命中路，按 RRF（`k=60`）依名次融合；删掉全表拉取与 `0.6/0.4` 加权。
4. **本地二阶段精排**：对融合候选算查询词元最小覆盖窗口、结构路径命中、覆盖率、余弦分与冗余度，用可判定的分层比较排序并去冗余；零外部调用，词元集合在精排与去冗余之间复用。
5. **判定与组装**：「有依据」由查询级向量分门槛加片段级词面/语义证据判定，删掉内容词命中数门禁；结构路径与相邻片摘要作为语境补进提示词，不进引用清单。
6. **降级**：零密钥或网关故障时走 BM25 单路 + 本地精排 + 抽取式回答，`degraded` 可见，任何失败都不退回旧数词规则。

## What Changes

- `retrieval.go` 重写为结构切片、词元化、查询变体与最小覆盖窗口；新增 `index.go`（BM25 倒排、结构路径路、相邻片查询）与 `rank.go`（RRF、本地精排、证据判定、去冗余）。
- `qa.go` 整段重写：按班缓存倒排索引（`buildMu` 串行化重建）、一次批量 embedding、多路并行 Qdrant、RRF 融合、候选证据判定、`Citation.Context` 只进提示词。删除 `ListChunksByClass` 每次提问全表拉取、`ScoreKeywords` 全语料打分、`norm`、`0.6/0.4` 融合与全量排序。
- `store.ChunkSeed` / `Chunk.HeadingPath` 与 `chunks.heading_path` 单列幂等迁移；`ReplaceChunks` 改为接收结构切片种子；新增 `GetMaterialTitle`。
- `qdrant` 侧不新增实现：集合维度校验、`Upsert` 分批与 `llm` 网关配置均沿用 PR #4；本变更只调用既有方法。
- 依据判定改为候选证据；主规约 R5 与对照表同步替换。
- 班级隔离（R2.2 / R7.2）、引用片段契约（R7.5）、注入防护（R5.5）、流式结束方式均不变。

## Capabilities

### Modified Capabilities

- `knowledge-retrieval`：R5「基于材料的检索问答」改为由结构切片、多路召回、本地二阶段精排与语境组装构成，不再以问题字符串的内容词个数判定依据，不在应用进程内对全班切片逐条打分。R5.1–R5.5 场景标题与承诺保持不变，新增 R5.6–R5.9 覆盖结构切片、不在进程内全表打分、重复片段与零密钥降级。

## Impact

- 代码：`backend/internal/retrieval/{retrieval,index,rank}.go`、`backend/internal/qa/qa.go`、`backend/internal/store/store.go`、`backend/internal/db/db.go`，以及两个测试文件；`qdrant` 侧沿用 PR #4 已合入的实现，本变更不改动。
- 依赖：无新服务、无新第三方库；新增代码全在既有 `retrieval` / `qa` 包内，`check-layering.mjs` 的 LAYERS 无需登记。
- 数据：`chunks` 增一列 `heading_path`，旧行默认空串，不破坏既有引用；历史材料不会自动升级，需用 `scripts/reindex-all.mjs` 按当前链路重建切片与向量，重建时先 `DeleteByMaterial` 再 `Upsert`，点 ID 与新切片 ID 对齐；结构切片更细，总点数随切片数变化。
- 行为：候选顺序与片段粒度改变，引用类 Go e2e 的期望片段与顺序需更新；零密钥降级路径保持可用且可见。
- 验证：质量门禁（gofmt / 分层 / 密钥 / build / vet / test / OpenSpec）已全绿；后端栈已启动，历史材料重索引完成 56/98 篇后因 embedding 网关当日额度耗尽中断，Go e2e 与浏览器 e2e 标为未验证，待额度恢复补齐后补跑。
