# Design: 补齐技能与 MCP 工具接入

## 现状（先核前提，避免重造）

| 已有能力 | 位置 | 本轮用法 |
| --- | --- | --- |
| 流式问答 + 未命中判定 | `httpapi/ask.go`、`qa/qa.go` | 在 `SystemPrompt()` 之前插入技能提示词；检索与 no_evidence 分支不动 |
| `qaService` 窄接口 | `httpapi/router.go` | 扩展为按班返回提示词与工具，handler 不直接碰 llm/qdrant |
| 按班隔离 + Bearer 令牌 | `auth`、`requireAuth`、`claims.ClassID` | 技能/服务器/调用记录一律带 class_id |
| 事务性发件箱 + 幂等键 | `index_tasks` | 调用记录沿用「只增不改 + 唯一约束」思路 |
| 单端口同源部署 | `web` embed、`docker-compose.yml` | mcp-server 独立服务同网，宿主用 Base URL 连接 |

## 决策

1. **技能是数据不是代码文件**：第 5 课要求「教师能维护技能」，若写成 Harness 规则文件则学生无法在运行时切换。故技能落库（按 class_id + name 唯一），教师通过接口配置，问答时按班加载。第 7 课「规范写成技能」另以 `AGENTS.md` 常驻规则满足，两者不冲突。
2. **技能提示词叠加而非替换**：`skill.SystemPrompt(active)` 在基础 `qa.SystemPrompt()` 之后追加「解题引导：先给思路、分步提问、不直接给最终答案」。关闭技能（active=false）时提示词与行为回到原样，保证「关闭后同一问题行为变化」可观测。
3. **无模型时也保留行为差异**：抽取式降级路径在技能启用时把固定引导句前置（`请先看：…`），使零密钥环境也能演示开关差异，不依赖真实网关。
4. **mcp-server 为独立 Go 工程**：`backend/cmd/mcp-server/` 独立 `main`，与主应用同一 module、同一镜像 `FROM build` 阶段多产出一个二进制，**不引入第三方依赖**（标准库实现 JSON-RPC 2.0），避免依赖审计新增高危。令牌从 `MCP_AUTH_TOKEN` 读，不设默认值、不进代码/前端/日志。
5. **连接 = 握手 + 工具发现两步**：`GET /api/mcp/servers/{id}/connect` 内部先 `initialize` 再 `tools/list`，任一步失败停在未连接并记录可读原因；两步都成功才整体替换工具清单（避免连续连接翻倍）。令牌响应只回 `token_configured` 布尔，绝不回明文。
6. **工具引用格式 `tool@server`**：保存技能时校验格式（工具名小写字母开头、无连字符；服务器名可含连字符）、工具在该服务器发现清单内、服务器已连接；三者任一不满足 → 400 可读错误。
7. **决策归模型、执行归宿主；无网关时按技能显式绑定降级**：有模型网关时把技能引用的工具清单随请求交给模型；模型在 `meta` 之前以结构化事件提出 `tool_call`，宿主按同一 inputSchema 校验参数后带令牌执行。无网关时按技能里显式保存的 `tool@server` 执行一次，保证演示链路可跑。两种路径都写调用记录。
8. **调用记录只增不改**：`mcp_tool_calls` 表无 UPDATE 路径，字段覆盖五问（tool@server / 成功|被拒|出错 / 触发人 / 会话与轮次 / 时间），教师仅本班可读，默认 limit=20 上限 50。
9. **越权与不存在同形**：跨班服务器/技能/调用记录一律 404，不泄漏存在性；学生访问管理接口 403。

## 失败路径

| 情况 | 行为 |
| --- | --- |
| 学生调用技能/服务器管理接口 | 403 统一错误体 |
| 跨班按 id 访问技能/服务器/记录 | 404，与不存在同形 |
| 技能工具引用格式错误 / 工具不在清单 / 服务器未连接 | 400 可读错误，不保存 |
| mcp-server 令牌缺失或错误 | JSON-RPC error `invalid_token`，不执行工具 |
| 连接握手或发现失败 | 停在未连接，`last_error` 记可读原因；检索/问答主路径不受影响 |
| 工具参数不符合 inputSchema | 宿主拒绝，`mcp_tool_calls` 记一条「被拒」 |
| 模型在首字后提出超限调用 | 优雅降级用已有信息作答，不报错中断 |
| 工具返回含指令式句式 | 整条丢弃，`meta.tool_calls` 记「被拒」 |
| 调用记录库故障 | 问答正常返回，ERROR 日志留痕（与既有审计失败策略一致） |

## 兼容性

- 三张新表全部 `CREATE TABLE IF NOT EXISTS`，旧库启动自动建表；不改任何存量表。
- 无技能、无服务器时问答提示词与事件序列与改动前逐字一致（回归保护）。
- `meta` 事件新增 `skill` / `tool_calls` 字段，旧客户端忽略即可。
- 新增路由不改变既有 `/api/` 404 兜底与 SPA 回落。
